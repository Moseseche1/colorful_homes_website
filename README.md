# Colorful Homes Construction Company Website

A responsive, static brand and lead-generation website for Colorful Homes Construction Company.

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Included
- Responsive desktop and mobile navigation
- Luxury brand presentation and service sections
- Project-type gallery with clear illustrative-image disclosure
- Accessible contact form with validation
- WhatsApp enquiry handoff (the visitor reviews and sends the message)
- Click-to-call and email links
- Search and social-sharing metadata
- Reduced-motion support

## Deployment
This is a static site and can be hosted on GitHub Pages or any static hosting provider. Configure the hosting provider to publish the repository root (where `index.html` lives).

## Before launch
- Confirm the displayed phone number, email address and office address.
- Replace illustrative gallery photography with approved Colorful Homes project photographs.
- Add a custom domain and analytics only after the domain/account configuration is confirmed.
- The contact form opens WhatsApp; it does not silently submit data to a database or send email.
